# arduino

james palma softflyers
controller for stepper motor von mises experiment

Serial @ **115200**. Boots idle — press `t` to start.

## Controls
| key | action |
|-----|--------|
| `t` | run / stop |
| `h` | enable toggle |
| `k` | kill |
| `d` | direction |
| `i` | impulse |
| `r` | reverse impulse |
| `+` | speed up |
| `-` | speed down |
| `]` | accel up |
| `[` | accel down |
| `?` | print this list |
